# 할 일 목록 (To-Do)

HTML, CSS, JavaScript만으로 만든 연습용 할 일 목록 웹앱입니다.

## 기능

- **달력 탭**: 월별 달력에 날짜마다 할 일 표시, 이전/다음 달 이동, 오늘로 이동
  - 날짜 칸을 누르면 그 날짜로 할 일 추가
  - 완료한 할 일은 회색 + 취소선, 진행중은 노란색, 미완은 파란색
- **목록 탭**: 전체 · 미완 · 진행중 · 완료로 나눠 보기, 체크박스로 완료 처리
- 할 일마다 **메모** 입력 가능 — 메모는 할 일을 눌렀을 때 상세 창에서만 보임
- 상세 창에서 상태 변경, 수정, 삭제
- 완료 항목 한 번에 삭제
- 브라우저(localStorage)에 자동 저장
- 다크 모드 자동 지원

## 실행 방법

`index.html` 파일을 브라우저로 열면 됩니다. 설치할 것이 없어요.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 (추가, 체크, 삭제, 필터, 저장) |
